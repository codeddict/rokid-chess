**대국 중에는 휴대폰과 안경만 사용합니다. PC, USB 중계, 서버 주소, 연결 키, Ollama가 필요 없습니다.** 안경 카메라의 연속 영상을 휴대폰에서 추적하고 양쪽 수를 자동 기록한 뒤 다음 수를 안경에 표시합니다. 시작할 때 한 번 판의 네 모서리와 현재 기보를 맞춰야 합니다.

## 휴대폰에서 시작

1. `artifacts/rokid-chess-v0.3.0.apk`를 휴대폰에 설치합니다. 기존 `로키드 체스` v0.1.0을 업데이트하는 패키지입니다. 안경 APK도 이 파일에 포함되어 있습니다.
2. Hi Rokid에서 안경을 연결한 상태에서 로키드 체스를 엽니다. **근처 기기** 권한을 허용합니다. 알림 권한을 허용하면 연결 유지 및 종료 알림을 볼 수 있습니다.
3. 최초에는 **안경 앱 설치**를 누르고 Hi Rokid 인증/전송 안내를 따릅니다. 안경의 `실물 체스 도우미` 앱에서 **카메라 권한**을 허용합니다. 이후에는 **안경 연결**로 엽니다. 설치에 Hi Rokid가 요구하는 Wi-Fi 전송을 허용해야 할 수 있습니다.
4. **내 말 색 변경**으로 아버지가 둘 색을 선택합니다. 새 대국은 실물 체스판을 기본 시작 배치로 둡니다. 중간 대국이면 **FEN 설정**으로 현재 배치와 차례를 먼저 설정합니다.
5. **로키드 카메라 촬영 · 위치 맞추기**를 누릅니다. 안경으로 판 전체를 바라보고, 휴대폰에 뜬 사진에서 체스판 바깥 모서리를 **a8 → h8 → h1 → a1** 순서로 누릅니다. 사진의 기물 배치와 앱의 배치가 같은지 확인하고 **이 판으로 맞추기**를 누릅니다. 좌표가 없는 판에서는 백 쪽에서 왼쪽 아래가 a1이고 오른쪽 아래가 h1입니다.
6. **접전 안내 / 최강 안내**을 선택한 뒤 **실물 판 안내 시작**을 누릅니다. 이후 양쪽 기물이 이동한 것을 자동 추적합니다. 한 수가 연속 관측에서 안정적으로 확인되면 기보에 반영하고, 아버지 차례에는 추천을 갱신합니다. 매번 사진 버튼이나 반영 확인을 누르지 않습니다.

휴대폰 화면을 꺼도 foreground service와 안경 연결을 유지합니다. 서비스가 종료되거나 절전 정책으로 제한되면 알림에서 다시 앱을 엽니다. 안경에서는 체스 앱이 전면에 있어야 카메라가 동작합니다. 안경에서 다른 앱으로 나가면 카메라를 닫습니다.

**실물 판 안내 일시 정지**는 카메라 스트림과 CPU 깨움 잠금을 해제합니다. 휴대폰의 **체스 연결 종료** 또는 알림의 **종료**는 엔진과 연결까지 종료합니다. 연결이 끊기면 라이브를 자동으로 재개하지 않으며 재연결 후 직접 시작합니다.

## 실물판 중심 화면

메인 화면은 안경 카메라의 실제 영상과 다음 이동 안내입니다. 예를 들어 **내 나이트 g1 → f3 / 앞으로 2칸 · 왼쪽 1칸**을 표시합니다. 방향은 선택한 아버지 색의 자리에서 바라본 기준입니다. 잡을 상대 말, 캐슬링 때 함께 옮길 룩, 앙파상 때 제거할 폰, 승격도 설명합니다.

판 위치를 맞추고 현재 관측이 확인된 때만 실제 카메라 미리보기 위에 이동 화살표를 그립니다. 이 화살표는 휴대폰 카메라 화면에 표시하며 안경 렌즈에는 말과 좌표를 텍스트로 안내합니다. 실제 공간에 고정되는 AR 오버레이는 아닙니다. 판을 아직 보여주지 않았거나 추적이 불안정하면 초기 배치에서 계산한 엔진 추천을 표시하지 않습니다.

화면 속 체스판은 **인식 보정 열기 / 닫기** 안에만 있습니다. 앱과 게임하는 기능이 아니라 실물 판을 잘못 읽었을 때 기보를 수정하는 도구입니다. 현재 버전은 기본 시작 배치에서 추적을 시작하며, 임의의 중간 판의 모든 기물 종류를 사진 한 장으로 자동 읽는 기능은 아직 없습니다. 중간 판은 보정 화면에서 FEN을 입력해야 합니다.

## 인식 방법과 보정

이 버전은 시작 배치를 알고 있는 체스판의 **수 이동 추적**입니다. 매 프레임마다 기물 종류 32개를 큰 생성형 모델로 새로 읽는 방식 대신, OpenCV로 판의 원근과 움직임을 맞추고 바뀐 칸들을 현재 국면의 합법 수와 대조합니다. PC에서 103초 걸리던 비전 모델 요청을 제거했습니다.

- 출발·도착 칸, 캐슬링의 4칸, 앙파상의 3칸 변화를 대조합니다.
- 판 추적이 충분하고, 다른 칸의 설명되지 않은 변화가 작고, 같은 합법 수가 최소 250ms 간격의 2개 이상 관측에서 확인되어야 자동 반영합니다.
- 손 가림, 큰 머리 움직임, 흐린 판, 모서리 이탈, 합법 수와 맞지 않는 변화는 자동 반영을 보류하고 안경에 관측 대기를 표시합니다.
- 3초 넘게 걸려 도착한 프레임은 버리고, 새 프레임을 기다립니다. 이전 이미지가 다음 요청과 섞이지 않도록 요청 ID와 조각 번호를 확인합니다.
- 승격 종류는 변화한 칸만으로 결정할 수 없습니다. 라이브를 멈추고 `e7e8q` 등의 수를 직접 입력하거나 판에서 승격 기물을 선택한 뒤 다시 판을 맞춥니다.
- 수동 입력, 되돌리기, 새 대국, FEN 변경 후에는 실물 판과 앱을 맞춘 뒤 다시 **판 맞추기**를 해야 합니다.

실물 기물의 높이, 반사, 그림자, 낮은 시선, 판 무늬와 이동 속도에 따라 잘못된 합법 수로 판정할 가능성은 남습니다. 말이 실제로 이동하지 않았는데 기보가 바뀌었으면 일시 정지하고 **되돌리기 → 판 다시 맞추기**로 보정하세요. 두 사람이 앱이 관측하기 전에 연속으로 빠르게 두면 수를 건너뛸 수 있습니다. 각 수를 둔 뒤 인식 표시를 확인하는 방식이 필요하며, 블리츠 수준의 무조건적인 추적을 보증하지 않습니다. 임의의 중간 판에서 기물 종류를 자동 복원하는 기능은 포함하지 않습니다.

## 속도와 확인 상태

| 구간 | 구현 / 검증 |
|---|---|
| 카메라 | Camera2 연속 YUV preview. 요청 후 다음 프레임만 JPEG로 인코딩하며 정지 사진 API를 반복 호출하지 않습니다. 대략 960×720 이하의 지원 크기를 선택합니다. |
| 무선 전송 | Hi Rokid/CXR custom channel. 12KB 조각, 한 프레임만 처리하고 다음 프레임을 요청합니다. 이전 프레임이 밀려 쌓이지 않습니다. |
| 판 추적 | 실제 Java/OpenCV 4.12 코드의 PC 테스트에서 중앙값 9ms / 95백분위 10ms. **휴대폰 실측값이 아닙니다.** |
| 수 확정 | 안정된 같은 수를 2개 이상 관측한 후 반영. 대기 간격 250ms에 촬영·전송·처리 시간이 추가됩니다. |
| 추천 | 휴대폰 ARM64 Stockfish 19, 분석 시간 300ms. 새 상대 수의 수준 평가에는 70ms 분석 2회가 추가됩니다. 초기 엔진 시작 시간은 별도입니다. |
| 실제 표시 지연 | **휴대폰/안경 미연결로 미측정.** 1~2초 안팎의 갱신을 목표로 설계했으나 달성했다고 확인한 상태는 아닙니다. |

휴대폰의 **인식 보정**을 열면 **수신 / 영상 / 엔진 ms**를 따로 표시합니다. 수신 시간에는 요청 이후 촬영·JPEG 변환·CXR 전송이 포함됩니다. 이 수치를 보고 실제 병목을 구분할 수 있습니다. 무선 간섭, 실제 기기 처리 능력, 발열, 펌웨어에 따라 속도가 달라집니다.

## 추천 모드

**접전**은 상대 최근 최대 8수의 최선수 대비 평가 손실을 추정하고 후보 최대 8개에서 비슷한 강도의 수를 고릅니다. 앞서면 조금 느슨하게, 불리하면 강하게 추천합니다. 200cp 이상의 큰 양보를 하지 않고, 최선수에 메이트 평가가 있거나 300cp 이상 불리하면 최선수를 우선합니다. 표본이 없으면 임시 35cp로 시작합니다. 공인 Elo나 접전 보장 수치는 아닙니다.

**최강**은 300ms 분석에서 찾은 최선수를 고릅니다. 엔진이 강해도 제한 시간, 관측 오류, 실제 플레이에 따라 승리를 보장하지 않습니다.

## 내부 구성

`안경 Camera2 YUV → 필요한 최신 프레임 JPEG → CXR → 휴대폰 OpenCV 판 추적 → chesslib 합법 수 대조 → 휴대폰 Stockfish → CXR → 안경 HUD`

안경에는 `com.sjtec.rokidchess.glasses`, 휴대폰에는 `com.sjtec.rokidchess`를 설치합니다. 기존 HQ 업무 앱은 변경하지 않았습니다. 휴대폰이 설치용 안경 APK를 운반하므로 안경 업데이트에 PC 연결이 필요 없습니다.

일시 정지 시 카메라를 닫고, 휴대폰의 프레임 요청이 6초간 없으면 안경도 카메라를 닫습니다. 라이브 추천은 새 관측이 없으면 4.5초 뒤 안경에서 만료됩니다. 프레임 수신이 5회 연속 실패하면 라이브를 멈춥니다. 서비스는 자동 재시작하지 않습니다. 라이브 중 CPU 깨움 잠금은 최대 6시간입니다.

이미지를 외부 서버로 보내거나 디스크에 기록하지 않습니다. 기보·모드는 휴대폰 앱 내부에 보관하며 재실행 시 복원하지만, 카메라 맞춤은 새로 합니다. Hi Rokid 인증 토큰은 메모리에만 사용합니다. HTTP 서버와 PC API 호출은 Android 앱에서 제거했습니다.

## 개발용 빌드 / 검사

설치 후 대국할 때는 아래 과정이 필요 없습니다.

```powershell
# 네이티브 엔진 재현 빌드: NDK r28c + SF19 + 체크섬 고정 NNUE
./scripts/chess.ps1 -Setup -Build

# Windows에서 실제 영상/엔진 단위 검사에 필요한 공식 테스트 런타임
python scripts/prepare-chess-tests.py
./scripts/chess.ps1 -Build -Tests

# 개발 중 USB로 휴대폰을 설치하는 선택 경로
./scripts/chess.ps1 -Install
```

ARM64 Android 12/API31 이상용입니다. Stockfish는 API31/NEON/PIE/16KB ELF 정렬로 빌드했고 신경망과 정적 C++ 런타임을 내장했습니다. PC에 설치된 Python·OpenCV·NDK는 개발/검사용이며 휴대폰 실행에 사용하지 않습니다.

검사는 시작 국면 perft, 캐슬링·앙파상·승격, 체크메이트·반복, 합법 수 대조, 연속 관측, 가림·추적 실패, 원근 정렬, 프레임 조각 혼합/과대 입력 거부와 실제 Stockfish UCI 통신을 포함합니다. Windows용 Stockfish와 OpenCV DLL이 없으면 해당 호스트 검사는 건너뛰므로 `prepare-chess-tests.py`를 먼저 실행합니다.

실기 인수 항목: 폰 설치 → 폰에서 안경 앱 무선 설치 → 카메라 권한 → 판 맞춤 → 양쪽 각 10수 자동 인식 → 화면 끈 상태 10분 → 접전/최강 전환 → 실측 지연 → 가림·고개 이동·무선 단절 후 보정 → 배터리·발열 확인. 현재 **실기 인수 전**입니다.

## 출처와 라이선스

- [Stockfish SF19](https://github.com/official-stockfish/Stockfish/releases/tag/sf_19): GPLv3. 소스 변경 없이 NDK r28c로 다시 빌드했습니다. APK의 `licenses/`와 `artifacts/rokid-chess-source-v0.3.0.zip`에 라이선스와 재현 소스·빌드 방법을 제공합니다.

- [chesslib](https://github.com/bhlangonijr/chesslib/tree/1.3.6), Apache Commons Lang: Apache-2.0.

이전 PC/USB 중계 버전은 `chess/`에 개발 이력으로 남아 있으며 현재 Android 앱에서 호출하지 않습니다.
