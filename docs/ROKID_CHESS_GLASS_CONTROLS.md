# 안경 버전 표시·난이도 설정 — v0.4.0

> 최신 v0.5.0은 **앱 내 업데이트와 실제 안경 응답·세 모드 엔진 점검**을 제공합니다. [점검 방법](ROKID_CHESS_UPDATER.md). 아래 안경 메뉴 조작은 그대로 사용할 수 있습니다.

휴대폰에서 [GitHub 최신 릴리스](https://github.com/codeddict/rokid-chess/releases/latest)의 **rokid-chess-v0.5.1.apk**를 설치한 다음, 앱의 **안경 업데이트**로 안경도 갱신합니다. 두 앱 모두 업데이트한 뒤 아래 순서로 시작하세요.

## 실물 판에서 시작

1. Hi Rokid에서 안경을 연결합니다. 휴대폰의 **실물 체스 도우미 → 안경 연결**을 누릅니다. 안경 카메라 권한을 허용합니다.
2. 실물 말을 기본 시작 배치로 놓습니다. 앱의 **내 말 색 변경**으로 아버지가 백/흑 중 무엇으로 둘지 고릅니다. 이전 대국 기록이 있으면 **실물 새 대국**으로 초기화합니다.
3. **실제 체스판 촬영 · 위치 맞추기**를 누르고, 사진에서 판의 바깥 모서리를 **a8 → h8 → h1 → a1** 순서로 고릅니다. 화면 제목에 다음 좌표와 어느 쪽 모서리인지 표시됩니다.
4. **실물 판 안내 시작**을 누르거나, 안경 메뉴에서 **안내 시작**을 선택합니다. 안경으로 판 전체가 보이게 바라봅니다.
5. 안내된 말을 실제 판에서 옮깁니다. 앱은 아버지와 아드님의 수를 관측해 기록하며, 아버지 차례에 다음 이동을 안내합니다. 초기 판 맞춤 후에는 휴대폰 화면을 꺼도 서비스를 유지합니다.

중간 판으로 시작하면 인식 보정 화면에서 전체 FEN을 먼저 설정해야 합니다. 현재 앱은 사진 한 장에서 임의의 중간 판의 모든 기물을 자동 복원하지 않습니다.

## 모서리 선택 기준

왼쪽·오른쪽은 **아버지가 앉은 자리에서 보는 기준**이며 좌표 순서는 색에 관계없이 같습니다.

선택하는 점은 **64칸 격자의 바깥 네 꼭짓점**입니다. 나무 장식 테두리의 끝이나 각 칸의 중앙을 선택하지 않습니다.

| 아버지 색 | 첫 번째 a8 | 두 번째 h8 | 세 번째 h1 | 네 번째 a1 |
|---|---|---|---|---|
| 백 | 아들 쪽 왼쪽 | 아들 쪽 오른쪽 | 내 쪽 오른쪽 | 내 쪽 왼쪽 |
| 흑 | 내 쪽 오른쪽 | 내 쪽 왼쪽 | 아들 쪽 왼쪽 | 아들 쪽 오른쪽 |

## 안경에서 조작

- **한 번 탭:** 난이도·버전 메뉴 열기. 메뉴에서는 선택 항목 확정.
- **앞/뒤 스와이프:** 메뉴 항목 이동.
- **두 번 탭:** 안내 화면으로 돌아가기.
- 메뉴 항목: **아슬아슬하게 이기기 / 중간 수준으로 이기기 / 압도적으로 이기기 / 안내 시작·일시 정지 / 버전 정보**.
- 방향 키와 확인 키 입력도 지원합니다. 같은 동작이 터치·키·시스템 방송으로 중복 전달되면 짧은 중복 입력을 걸러냅니다.

난이도 선택 시 **휴대폰에 적용 중…**이라고 표시합니다. 휴대폰이 설정을 적용하고 응답한 뒤에만 **적용 완료**가 표시되고 안내 화면으로 돌아갑니다. 실패 시 메뉴를 유지하고 이유를 표시합니다. 기존 영상을 처리 중이면 설정 한 건을 대기시켜 처리 후 적용합니다. 재전송은 같은 요청 ID를 사용해 중복 적용을 막습니다.

## 세 모드의 의미

| 모드 | 추천 방식 |
|---|---|
| 아슬아슬 | 상대 최근 수의 손실을 참고하고, 작은 우세(+80cp 부근)를 유지할 수 있는 수를 후보에서 고릅니다. 최선수보다 양보하는 폭은 최대 200cp입니다. |
| 중간 | 더 큰 우세(+250cp 부근)를 목표로 하고, 양보 폭을 최대 100cp로 제한합니다. |
| 압도적 | 양보 없이 Stockfish가 분석한 최선수를 추천합니다. |

현재 우세가 목표보다 작거나 불리하면 강한 수를 추천합니다. 확정 메이트 평가가 있으면 이를 우선하며, 아슬아슬·중간 모드에서도 의도적으로 불리한 후보를 고르지 않습니다. 후보가 없으면 최선수를 사용하므로 모드가 달라도 같은 수를 추천할 수 있습니다. 이 수치는 평가 목표이며 승리나 특정 점수 차이를 보장하지 않습니다.

실제 계산은 **Stockfish 19**가 휴대폰에서 수행합니다. 판 추적은 OpenCV가 맡습니다. 기본 분석 시간은 300ms이고, 새 상대 수의 수준 평가에는 짧은 추가 분석이 필요합니다. 신경망·엔진은 APK에 포함되어 있어 PC 엔진이나 클라우드 분석이 필요 없습니다.

## 버전 표시

안경 화면 위에 **안경 v0.4.0 · 폰 v0.4.0 / 모드: 중간**처럼 표시합니다. 안경 버전은 실행 중인 안경 APK의 BuildConfig에서, 폰 버전과 실제 모드는 휴대폰 응답에서 가져옵니다. 응답 전에는 폰 버전을 추정하지 않고 **확인 중**이라고 표시합니다. 메뉴의 **버전 정보**에서도 확인할 수 있습니다.

폰에서 바꾼 모드도 안경에 반영되고 설정은 휴대폰에 저장됩니다. 재실행 후에는 안경이 휴대폰 상태를 다시 조회합니다. v0.3.0의 `balanced` 설정은 새 **아슬아슬** 모드로 이전합니다.

## 검증 범위

순수 Java 검사로 메뉴 이동·선택, ACK 대기/실패, 지연 응답/이전 세션 거부, 세 모드 후보 선택·메이트 보호, 제어 요청 유효성, 백/흑 모서리 설명을 확인합니다. 앱 빌드와 lint도 실행합니다. 이 검사는 실제 안경의 터치 감지·렌즈 가독성·CXR 전송 성공이나 실물 체스판 정확도의 인수를 대체하지 않습니다. 실기 조작은 확인 전입니다.
