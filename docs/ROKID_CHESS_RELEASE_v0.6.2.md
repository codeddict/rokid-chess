**안경 사진 수신 시간 초과 경로를 수정했습니다.** 휴대폰 앱의 **앱 업데이트 확인 / 설치**로 v0.6.2를 설치하고 **안경 앱 설치 / 업데이트**로 안경도 갱신하세요. 이후 휴대폰 연결을 끊고 안경 앱 목록에서 직접 실행합니다.

- 기존처럼 미리보기 프레임을 버리고 정지 JPEG만 기다리지 않습니다. 실제 YUV 미리보기 프레임을 받아 사진·모서리 맞추기·연속 관측으로 전달합니다.
- 프레임이 오지 않으면 지원하는 다른 해상도, 미리보기 출력 조합, JPEG 및 다른 카메라를 제한된 횟수/시간 안에서 자동 시도합니다. 정상 작동한 경로는 연속 관측에 재사용합니다.
- 1920×1080 프레임이 엄격한 2,000,000픽셀 제한 때문에 제외되지 않도록 수정했습니다.
- 준비 중/프레임 대기/사진 수신 완료를 표시합니다. 실패 후 **버전·상태**에서 출력 경로와 ‘결과 / 이미지’ 수치를 확인할 수 있습니다. 사진은 서버에 전송하지 않습니다.
- 촬영 중단·이전 프레임·이전 타이머·UI 사진 전달의 순서를 검사합니다. 대국 중 카메라/해상도가 달라지면 추천을 멈추고 판을 다시 맞추도록 안내합니다.
- 휴대폰 없이 **미리보기 YUV → 사진 → 네 모서리 → e2e4/e7e5 안정 관측 → 실제 Stockfish 추천**으로 이어지는 호스트 회귀 시험을 추가했습니다. 실제 안경의 렌즈/펌웨어 촬영 성공을 검증한 시험은 아닙니다.

**기기를 연결할 수 없어 실제 안경에서의 촬영·위치 맞추기·대국 성공은 아직 확인하지 못했습니다.** 재시작 안내만 바꾼 버전이 아니라 프레임 수신 경로를 수정한 버전이며, 오류가 남으면 안경의 **버전·상태**에 표시된 진단 수치로 다음 원인을 구분할 수 있습니다.
