# 안경 단독 체스 — v0.6.2

v0.6.2 촬영 수정: YUV 미리보기를 버리지 않고 직접 사진으로 변환합니다. 첫 경로에서 프레임이 오지 않으면 지원 해상도/출력 조합을 자동 변경합니다. 안경 화면에 ‘준비 → 프레임 대기 → 사진 수신 완료’가 표시되고 사진·모서리 커서로 이어져야 정상입니다. **버전·상태**에 마지막 경로와 결과/이미지 수치를 표시합니다.

v0.6.2은 촬영, 네 모서리 맞추기, OpenCV 판 추적, Stockfish 19 분석, 난이도 설정과 기보 저장을 모두 **안경 내부**로 옮겼습니다. 대국 중 휴대폰·Hi Rokid·인터넷 연결을 사용하지 않는 구조입니다. 휴대폰 앱은 안경 APK 설치와 업데이트에만 사용합니다.

**현재 실물 안경이 개발 PC에 연결되어 있지 않아, 안경의 Camera2 접근·권한 화면 조작·가독성·실제 속도·체스판 정확도는 실기 검증 전입니다.** 기존 v0.5.2의 공식 사진 API 경로 대신 안경 앱이 Android Camera2를 직접 사용합니다. 펌웨어가 일반 앱의 카메라 접근을 제한하면 실제 오류 확인이 필요합니다.

## 설치 후 단독 시작

1. 휴대폰의 기존 체스 앱에서 **앱 업데이트 확인 / 설치**로 v0.6.2을 설치합니다.
2. 새 휴대폰 화면의 **안경 앱 설치 / 업데이트**를 누릅니다. 안경 APK에 약 100MB 엔진·신경망이 포함되어 전송 시간이 걸릴 수 있습니다. 전송 중 앱을 열어 두세요.
3. 설치가 끝나면 안경의 **앱 목록에서 ‘실물 체스 도우미’를 직접 실행**합니다. 화면에 **안경 단독 v0.6.2**이 표시되어야 합니다. 설치 후에는 휴대폰의 설치 연결을 종료할 수 있습니다.
4. 안경에서 **한 번 탭 → 메뉴**, **앞/뒤 스와이프 → 항목 이동**, **탭 → 선택**합니다. ‘새 대국 · 내가 백’ 또는 ‘새 대국 · 내가 흑’을 고르고 초기화 확인을 합니다. 이전 기보를 이어가려면 새 대국 대신 ‘판 촬영·맞추기’를 선택합니다. 실제 배치와 저장된 기보가 같아야 합니다.
5. 카메라 권한 화면이 나오면 **안경 앱의 카메라 권한**을 허용합니다. Hi Rokid 카메라 권한과 별개입니다.
6. 안경으로 판 전체를 바라봅니다. 사진이 촬영되면 **안경 화면에 사진과 네 모서리 커서**가 나타납니다. 휴대폰으로 사진을 보내지 않습니다.

## 안경에서 네 모서리 지정

좌표 순서는 **a8 → h8 → h1 → a1**입니다. 64칸 격자의 바깥 꼭짓점을 가리키세요. 처음 표시되는 커서 위치는 편집 시작 위치이며 자동 인식 결과가 아닙니다.

각 모서리에서 다음 조작을 반복합니다.

1. 스와이프로 **좌우 위치 조정**을 선택하고 탭합니다.
2. 스와이프로 커서를 좌우로 움직입니다. 탭하면 항목 선택으로 돌아갑니다.
3. 스와이프로 **위아래 위치 조정**을 선택하고 탭합니다. 스와이프로 위아래를 맞춘 뒤 탭합니다.
4. 스와이프로 **이 모서리 확정**을 선택하고 탭하면 다음 모서리로 넘어갑니다.

커서가 처음부터 정확하면 **이 모서리 확정**만 선택하면 됩니다. ‘이전 모서리’, ‘다시 촬영’, ‘맞추기 취소’도 같은 방식으로 선택합니다. 두 번 탭은 조정 중이면 항목 선택으로, 항목 선택 중이면 이전 모서리로 돌아갑니다.

아버지가 **백**이면 아들 쪽 왼쪽 → 아들 쪽 오른쪽 → 내 쪽 오른쪽 → 내 쪽 왼쪽입니다. **흑**이면 내 쪽 오른쪽 → 내 쪽 왼쪽 → 아들 쪽 왼쪽 → 아들 쪽 오른쪽입니다. 좌우는 아버지 자리 기준이며 각 단계에 설명이 표시됩니다.

## 안내 시작과 난이도

- 네 모서리 적용 후 메뉴에서 **안내 시작**을 선택합니다. 사진 수신·판 처리가 끝나면 다음 사진을 자동 촬영합니다.
- 메뉴의 **아슬아슬하게 이기기 / 중간 수준으로 이기기 / 압도적으로 이기기**가 안경 내부의 실제 엔진 분석에 적용됩니다. 상황에 따라 같은 수가 나올 수 있으며 승리를 보장하지 않습니다.
- 안내 중 아버지와 아들의 수를 모두 관측합니다. 한 수가 안정적으로 확인될 때만 기보에 반영합니다. 아버지 차례에 움직일 말과 출발·도착 칸을 안내합니다.
- 한 번 탭하면 메뉴, 두 번 탭하면 안내로 돌아갑니다. 메뉴에서는 다음 촬영을 기다립니다. 앱을 벗어나면 카메라와 자동 안내를 정지합니다.
- ‘한 수 되돌리기’ 뒤에는 실제 말도 되돌리고 판을 다시 맞춥니다. 기보와 실제 배치가 다르면 새 대국으로 시작하세요. 임의의 중간 판을 사진 한 장으로 자동 복원하지 않습니다. 승격의 자동 확정은 지원하지 않으며 승격 상태에서는 안내를 중지합니다.

## 카메라 오류

권한 거부와 지원 출력 정보를 안경에서 확인합니다. YUV 미리보기 단독 출력을 먼저 사용하고, 프레임이 오지 않으면 다른 해상도/미리보기 조합/JPEG/카메라를 자동 시도합니다. 경로마다 최대 6초, 전체 요청 약 35초 범위이며 화면에 현재 단계가 표시됩니다. 지원 크기만 선택하고 최대 2,500,000픽셀로 제한해 Full HD도 처리합니다.

실패하면 안경 메뉴의 **버전·상태**를 열어 **카메라 ID / YUV 또는 JPEG / 해상도 / 결과 N / 이미지 M**을 확인하세요. 결과 수는 카메라 촬영 완료 콜백, 이미지 수는 앱에 도착한 실제 영상 버퍼입니다. 두 수치를 구분해 렌즈/펌웨어 프레임 미출력과 버퍼 전달 문제를 추적합니다. 사진 자체는 로그나 서버에 전송하지 않습니다.

대국 중 카메라 ID·해상도·형식이 바뀌면 기존 좌표로 말을 반영하지 않고 안내를 멈춥니다. 메뉴에서 판을 다시 맞추세요.

## 검증

안경 APK에는 자체 Stockfish 실행 파일·NNUE·OpenCV·체스 규칙 코드가 들어갑니다. 안경 앱에서 인터넷·Bluetooth 권한과 CXR 의존성을 제거합니다. Stockfish는 한 스레드/16MB 해시로 실행하며 실제 발열·배터리·처리 시간은 실기로 확인해야 합니다. 코너 조작, EXIF 사진 좌표 일치, 게임·판 추적·실제 엔진 모드 분석과 휴대폰 업데이트 입력 검사를 실행합니다.
