**휴대폰 연결 없이 대국하도록 안경 단독 구조로 변경했습니다.** 촬영·모서리 맞추기·OpenCV 추적·Stockfish 19 분석·난이도 설정·기보 저장은 안경 내부에서 실행합니다. 휴대폰 앱은 설치/업데이트용입니다.

1. 휴대폰 APK **rokid-chess-v0.6.1.apk**를 설치합니다. 기존 v0.5.1 이상 앱의 업데이트 버튼으로 받을 수도 있습니다.
2. 새 휴대폰 화면에서 **안경 앱 설치 / 업데이트**를 누르고 완료를 기다립니다. 전송 중 휴대폰 앱을 열어 두세요.
3. 안경 앱 목록에서 **실물 체스 도우미**를 직접 열어 **안경 단독 v0.6.1** 표시를 확인합니다. 이후 대국에는 휴대폰 연결이 필요 없는 구조입니다.
4. 안경에서 탭 → 메뉴 → 새 대국(백/흑) → 초기화 확인 → 카메라 권한 허용 → 사진 위 모서리 조정 → 안내 시작 순서로 진행합니다.

스와이프로 **좌우/위아래 조정** 항목을 고르고 탭한 뒤 스와이프로 커서를 옮깁니다. 탭해 항목 선택으로 돌아와 **이 모서리 확정**을 선택합니다. a8/h8/h1/a1 네 점을 모두 확인해야 합니다. [자세한 사용법](https://github.com/codeddict/rokid-chess/blob/main/docs/ROKID_CHESS_STANDALONE.md).

**안경 Camera2 접근·권한 화면·실제 가독성·속도·실물 체스판 정확도는 기기 미연결로 실기 검증 전입니다.** 휴대폰을 통한 이전 촬영 콜백 경로를 제거했지만, 실제 펌웨어가 일반 앱의 카메라 접근을 허용하는지는 기기에서 확인해야 합니다.

안경 APK 자체가 필요하면 **rokid-chess-glasses-v0.6.1.apk**, 전체 대응 소스와 정확한 Stockfish NNUE는 **rokid-chess-source-v0.6.1.zip**입니다. 해시는 **SHA256SUMS.txt**, 버전 정보는 **update.txt**에 있습니다. Stockfish 19는 GPLv3로 제공합니다.

모서리 좌표 적용 실패 시 오류 이유를 안경 화면에 표시하도록 보완했습니다. 모서리를 다시 조정하거나 다시 촬영할 수 있습니다.
