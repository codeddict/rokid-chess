# 앱 안에서 업데이트·안경 점검 — v0.5.1

> 최신 v0.6.0은 **안경 단독 실행**입니다. 휴대폰 연결 없이 촬영·위치 맞추기·엔진 분석을 안경에서 처리합니다. 아래는 이전 버전 설명이며, [안경 단독 사용법](ROKID_CHESS_STANDALONE.md)을 먼저 확인하세요. 실제 기기 동작은 실기 확인 전입니다.

> v0.5.2 카메라 수정: **앱 업데이트 → 안경 업데이트 → 안경 연결** 후 Hi Rokid **카메라 권한**을 허용하고 **로키드 카메라 촬영 · 위치 맞추기**를 누르세요. [최신 촬영 안내](ROKID_CHESS_CAMERA.md). 촬영은 Rokid 시스템 사진 API이며, 아래 Camera2/YUV 경로 설명은 이전 버전 기록입니다.

휴대폰에서 [GitHub 최신 릴리스](https://github.com/codeddict/rokid-chess/releases/latest)를 열고 Assets의 **rokid-chess-v0.5.1.apk**를 한 번 설치합니다. 기존 앱을 삭제하지 마세요. v0.5.0 이하는 옛 웹하드 주소와 파일 경로로 고정되어 있어 이번 이전 업데이트는 앱 버튼으로 받을 수 없습니다. v0.5.1부터는 **앱 업데이트 확인 / 설치**가 GitHub Releases에서 업데이트 안내와 APK를 받습니다. 다운로드에 GitHub 로그인은 필요 없습니다.

APK와 대응 소스·정확한 NNUE는 GitHub Releases에 함께 제공합니다. 기존 웹하드의 체스 폴더는 사용자가 삭제한 뒤 비어 있음을 SFTP로 확인했으며 이번 이전에서 대용량 파일을 다시 올리지 않습니다. 이미 발생한 트래픽은 파일 삭제로 환급되거나 초기화되지 않습니다.

## 이후 업데이트

1. 앱의 **앱 업데이트 확인 / 설치**를 누릅니다.
2. 새 버전이 있으면 **다운로드 / 설치**를 누릅니다. 다운로드 진행률을 표시하고, 크기·SHA256·패키지·버전·현재 앱과 동일한 서명을 검증합니다.
3. 처음 한 번은 Android에서 이 앱의 설치 출처를 허용해야 할 수 있습니다. 설정 화면에서 돌아오면 설치를 이어갑니다. Android 설치 확인은 직접 누릅니다.
4. 설치 후 앱을 열고 바로 옆의 **안경 업데이트**를 누릅니다. Hi Rokid 전송 안내에 따라 포함된 안경 앱을 갱신합니다.

최신 버전이면 현재 버전을 표시합니다. 다운로드가 완료된 설치 대기 파일은 Activity/설정 화면 전환 후에도 복원하고 다시 검증합니다. 취소 후 설치 창이 즉시 반복해서 열리지 않으며, 업데이트 버튼을 다시 눌러 재시도할 수 있습니다. 앱은 자체 서명 APK만 설치 대상으로 허용하며, APK 캐시 폴더만 FileProvider로 공유합니다. 일반적인 Android 앱이므로 설치 확인을 우회하는 무인 업데이트는 하지 않습니다.

## 실제 안경과 추천 모드 점검

휴대폰과 안경을 모두 v0.5.1로 업데이트하고 연결한 뒤 **안경 버전·난이도 점검**을 누릅니다.

- 안경 앱에 요청 ID를 보내 실행 중인 안경 버전, 안경이 확인한 휴대폰 버전, 표시 중인 모드와 헤더 문자열을 응답받습니다. 응답이 없으면 미확인으로 표시합니다. v0.4.0 안경 앱은 이 새 점검 요청을 지원하지 않습니다.
- 안경에서 모드를 바꿔 ACK를 받은 뒤에도 표시 상태를 다시 조회합니다. 폰의 현재 설정과 안경 표시 모드를 비교합니다.
- 휴대폰의 **최근 엔진 분석 모드**는 실제 `LocalCoach.Advice` 결과에 붙은 모드입니다. 모드 설정은 새 모드로 분석을 마친 뒤에만 확정됩니다.
- 실제 Stockfish 19로 고정된 샘플 국면을 아슬아슬/중간/압도적 모드로 각각 분석합니다. 모드 전달, 합법적인 추천과 샘플 기록 불변을 대조합니다. 사용자의 실제 대국 위치나 수를 수정하지 않습니다.
- 모드가 달라도 같은 수를 추천하는 것은 정상일 수 있습니다. 메이트, 불리한 상황, 제한된 후보에서는 최선수가 같을 수 있습니다.
- **점검 결과 복사**로 텍스트를 복사해 확인을 요청할 수 있습니다. 사진이나 기보를 외부 서버에 자동 전송하지 않습니다.

점검 중에는 새 프레임 처리를 잠시 기다리고, 완료 후 실제 판 관측을 재개합니다. 점검은 안경 앱이 응답한 표시 문구와 상태를 대조하는 기능입니다. 실제 렌즈에서 글씨가 얼마나 잘 보이는지와 실물 판 인식 정확도를 원격으로 측정하는 기능은 아닙니다.

## 검증

실제 Windows Stockfish를 사용하는 동일 Java `LocalCoach`/`ModeDiagnostics` 검사에서 세 모드별 분석을 실행했습니다. 샘플에서 각각 c2c3/d2d3/e2e4를 추천했고 모드·합법 수·샘플 기록 불변 검사를 통과했습니다. 이 수들은 사용자의 현재 실물 판에 대한 추천이 아닙니다.

추가 검사는 105MB급 APK 허용, 잘못된 호스트/HTTP/패키지/크기/해시 거부, 설치 대기 복원과 변조/과대 메타데이터 거부를 포함합니다. 실제 Android 설치 화면, 안경 응답 왕복, 렌즈 표시는 현재 기기 연결이 없어 실기 확인 전입니다.

## 배포 경로와 검증

버전 안내는 `https://github.com/codeddict/rokid-chess/releases/latest/download/update.txt`입니다. APK는 같은 저장소의 버전별 release 경로만 허용합니다. 리디렉션은 HTTPS GitHub 저장소 및 지정된 GitHub release asset 호스트에 한해 최대 5회 허용하며, APK 크기·SHA256·패키지·상향 버전·설치 앱과 같은 서명 확인을 유지합니다. 앱에 GitHub 토큰을 넣지 않습니다.

v0.5.1은 총 62개 테스트(실패·오류·건너뜀 0)와 양쪽 빌드/lint 오류 0을 확인했습니다. GitHub URL 경로, 다른 저장소·유사 호스트·HTTP·사용자 인증정보가 있는 URL 거부를 포함합니다. 실기 Android 설치와 실제 안경 응답은 기기 연결 전이라 미확인입니다.
