**로키드 안경 카메라 촬영 경로를 수정했습니다.** 휴대폰 앱의 **앱 업데이트 확인 / 설치**로 갱신하거나 아래 `rokid-chess-v0.5.2.apk`를 받아 설치하세요. 설치 후 **안경 업데이트 → 안경 연결** 순서로 진행하고 Hi Rokid의 **카메라 권한**을 허용하세요.

- 안경 앱의 직접 Camera2 촬영 대신 Rokid 공식 CXR 사진 API로 촬영·수신합니다. 안경 앱과 시스템 카메라의 동시 점유를 피합니다.
- 휴대폰에서 카메라 권한도 요청하도록 수정했습니다. 이전 버전은 Hi Rokid 기기 관리 권한만 요청했습니다.
- **로키드 카메라 촬영 · 위치 맞추기** 버튼으로 안경 사진을 받습니다. 촬영 요청·수신 완료·권한 부족·SDK 오류·시간 초과를 구분합니다.
- 중복 촬영과 취소 뒤 늦게 도착하는 사진을 구분하고, 휴대폰 앱으로 돌아오면 보정 대기 사진을 다시 표시합니다.
- 대국 안내 중에는 사진 수신·처리가 끝나면 다음 촬영을 자동 요청합니다. 실제 지연과 물리 체스판 정확도는 기기 미연결로 실기 검증 전입니다.
