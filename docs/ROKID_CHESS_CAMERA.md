# 로키드 카메라 촬영 — v0.5.2

이번 버전은 Rokid CXR-L 공식 사진 API로 안경에서 촬영하고 휴대폰에서 이미지 콜백을 받습니다. 안경 HUD 앱이 Camera2를 직접 열지 않으므로 Rokid 시스템 카메라와 동시에 카메라를 점유하지 않습니다. 휴대폰 전면·후면 카메라를 선택하는 흐름은 사용하지 않습니다.

## 업데이트 후 시작

1. 휴대폰 체스 앱에서 **앱 업데이트 확인 / 설치 → 다운로드 / 설치**로 v0.5.2를 설치합니다. Android 설치 확인을 완료하고 앱을 다시 여세요.
2. **안경 업데이트**를 눌러 안경 앱도 v0.5.2로 갱신합니다.
3. **안경 연결**을 누릅니다. Hi Rokid에서 **카메라**와 기기 관리 권한을 허용합니다. v0.5.1까지는 기기 관리 권한만 요청했으므로 새 카메라 권한 확인이 필요합니다.
4. 실제 말을 초기 배치에 놓고 본인의 백/흑을 맞춥니다. 이전 기록이 있으면 인식 보정의 **실물 새 대국**으로 초기화합니다.
5. 안경으로 판 전체를 바라보며 휴대폰의 **로키드 카메라 촬영 · 위치 맞추기**를 누릅니다.
6. **로키드 사진 수신 완료**와 사진이 뜨면 a8 → h8 → h1 → a1 모서리를 지정하고 **이 실제 판으로 맞추기**를 누릅니다. 좌우 기준과 백/흑별 순서는 [모서리 안내](ROKID_CHESS_GLASS_CONTROLS.md)를 참고하세요.
7. **실물 판 안내 시작**을 누릅니다. 한 장의 수신·처리가 끝나면 다음 안경 사진을 자동 요청합니다. 대국 중 매번 촬영 버튼을 누를 필요는 없습니다.

## 문제가 생기면

- **Hi Rokid 카메라 권한 없음:** 안경 연결을 다시 눌러 새 권한 요청을 허용합니다.
- **촬영 요청 거부 / SDK 촬영 오류:** Hi Rokid 연결 상태, 권한 및 카메라를 사용하는 다른 앱을 확인하고 안경 연결을 다시 누릅니다.
- **15초 동안 사진 응답 없음:** SDK 사진 콜백에는 요청 ID가 없어 이전 사진을 새 요청의 사진으로 취급하지 않도록 해당 세션을 재사용하지 않습니다. **안경 연결**로 새 연결을 만든 뒤 재촬영합니다.
- **사진 수신 완료 뒤 보정 화면이 안 보임:** 휴대폰 체스 앱으로 돌아오면 아직 보정하지 않은 사진을 다시 표시합니다.
- **점검 결과 복사**에는 마지막 촬영 상태, 사진 바이트 수와 수신 시간도 포함됩니다. 사진 자체를 서버로 보내지 않습니다.

## 검증 범위

Rokid 공식 로컬 CXR-L `PhotoUsageViewModel`과 SDK 1.1.2의 실제 API를 대조했습니다. `GlassPermission.CAMERA`, `setCXRImageCbk`, `takePhoto(1024,768,70)`를 사용합니다. 촬영 중복, 취소 후 지연 사진, 시간 초과, 이전 타이머, 연결 끊김에 대한 상태 검사를 추가했습니다.

현재 개발 PC에 연결된 기기가 없어 이번 버전의 **실물 사진 수신, 연속 촬영 지연과 체스판 인식 정확도는 실기 검증 전**입니다. 카메라 준비·전송 시간에 따라 관측 간격이 달라집니다. 인식이 불확실한 사진으로 기보를 강제 반영하지 않습니다.
